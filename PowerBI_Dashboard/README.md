# 📊 Employee Attrition Analytics

## 📌 Project Overview

Employee Attrition Analytics is an interactive Power BI dashboard designed to analyze employee attrition and understand the factors that influence employee turnover.

The dashboard provides a clear view of employee demographics, job roles, departments, salary-related information, and attrition patterns to help organizations identify areas that may require attention.

## 🎯 Project Objectives

- Analyze overall employee attrition
- Identify departments and job roles with higher attrition
- Understand attrition patterns based on employee demographics
- Analyze the relationship between salary, experience, and attrition
- Compare employee satisfaction and attrition
- Provide meaningful business insights through interactive visualizations

## 🛠️ Tools & Technologies

## 📈 Dashboard Features

- Total Employee KPI
- Attrition Count
- Attrition Rate
- Average Employee Age
- Department-wise Attrition Analysis
- Job Role-wise Attrition Analysis
- Gender-wise Attrition Analysis
- Age-wise Attrition Analysis
- Salary Analysis
- Employee Satisfaction Analysis
- Interactive Filters and Slicers

## 🔄 Data Preparation

The employee dataset was prepared using Power Query before developing the dashboard.

The data preparation process included:

- Checking and handling missing values
- Removing duplicate records
- Correcting data types
- Cleaning employee-related information
- Creating required calculated fields
- Preparing data for visualization and analysis

## 💡 Key Business Insights

The dashboard helps organizations understand:

- Which departments have higher employee attrition
- Which job roles experience more employee turnover
- How employee age and experience relate to attrition
- Whether salary levels influence employee attrition
- How employee satisfaction is associated with turnover
- Which employee segments may require retention strategies
